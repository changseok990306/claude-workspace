# 광고 운영 (`ads/`)

어도비 광고 계정을 운영하면서 **캠페인별 기록 · 성과 · 예산 · 소재**를 한곳에서 관리하는 웹페이지예요.
서버나 설치가 필요 없고, `index.html` 하나로 열려요. 다크 모드를 지원해요 (우측 상단 스위치).

## 열어 보기

1. `ads/index.html` 파일을 **더블클릭** (크롬·엣지 등 브라우저로 열려요. 인터넷이 없어도 돼요)
2. 처음이라면 **“예시 데이터로 둘러보기”** 버튼을 눌러 보세요. 가짜 캠페인 3개가 들어가요.
   - 지우고 싶으면 `데이터 → 모든 데이터 지우기`, 또는 “예시 ·”로 시작하는 캠페인을 삭제하세요.

## 화면 구성

위쪽 탭 4개 + 왼쪽 캠페인 목록이에요. 왼쪽에서 캠페인을 고르면 모든 탭이 그 캠페인만 보여 줘요. (“전체”는 모두)
캠페인마다 색이 달라서 어디서든 구분돼요.

| 탭 | 하는 일 |
|---|---|
| **기록장** | 캠페인별로 날짜와 메모를 남겨요. 날짜 최신순, 실시간 검색(내용·날짜·캠페인 이름) |
| **성과** | 날짜별 노출·클릭·비용·전환을 입력/CSV로 넣으면 **비용·노출·클릭·CTR·CPC·전환·CPA** 카드와 추이 차트, 표가 나와요. 기간 선택·검색·CSV 내보내기 지원 |
| **예산·일정** | 캠페인별 예산과 집행 기간을 등록하면 성과 탭의 비용으로 **집행액·잔액·소진율·남은 일수**를 자동 계산해요. 집행 속도가 빠르면 “속도 주의”와 권장 일 집행액을 알려 주고, 일정은 막대 그래프(검은 선 = 오늘)로 보여요 |
| **소재** | 광고 소재를 준비 / 집행 중 / 종료로 나눠 관리하고, 소재마다 점검 체크리스트(규격·문구·링크·UTM·승인 등)를 체크해요 |

## 데이터 넣기

**1) 직접 입력** — 각 탭의 입력 칸 (성과·예산·소재는 “＋ 추가” 줄을 눌러 펼쳐요)
- 성과는 같은 캠페인·같은 날짜를 다시 저장하면 **덮어써요**. (이미 있는 날짜를 고르면 값을 자동으로 불러와요)

**2) CSV 파일 업로드** — 우측 상단 `데이터` → `CSV 가져오기`
- 파일을 고르면 **바로 반영하지 않고 미리보기**를 먼저 보여 줘요 (몇 행을 읽었는지, 문제가 있는 줄 번호와 이유, 새로 만들어질 캠페인, 덮어쓸 행 수).
- 문제가 있는 줄은 건너뛰고 나머지만 가져와요. 파일은 이 브라우저 안에서만 읽어요. 어디로도 올라가지 않아요.
- `양식 CSV 받기`로 빈 양식을 받아 채우면 편해요. 엑셀·구글 시트에서 “CSV(UTF-8)”로 저장하세요. (최대 2MB, 5000행)

| 종류 | 필요한 열 (한글/영어 모두 가능) |
|---|---|
| 성과 | **날짜**(date), **캠페인**(campaign), 노출(impressions), 클릭(clicks), 비용(cost), 전환(conversions) — 숫자 열은 하나 이상 |
| 기록 | **날짜**, **캠페인**, **내용**(content) |
| 예산 | **캠페인**, **시작일**(start), **종료일**(end), **예산**(amount), 메모(memo) |

- 날짜는 `2026-11-08`, `2026/11/8`, `2026.11.08`, `20261108`, `2026년 11월 8일` 모두 읽어요.
- 숫자의 쉼표·`원`·`%`·`₩`는 알아서 처리해요 (`"12,000"` → 12000).
- 파일에 없는 캠페인 이름은 **자동으로 새 캠페인으로 만들어요** (체크를 끄면 그 행은 건너뛰어요).
- `데이터 → CSV 내보내기`로 내보낸 파일은 그대로 다시 가져올 수 있어요.

## ⚠️ 데이터는 어디에 저장되나요?

**지금 쓰고 있는 이 브라우저 안에만** 저장돼요 (브라우저의 `localStorage`).

- 새로고침·창 닫기에는 남아 있어요.
- **다른 컴퓨터·다른 브라우저·시크릿 창에서는 안 보여요.** 보는 사람과 공유되지도 않아요.
- 브라우저의 “사이트 데이터 삭제”를 하면 **사라져요**. → `데이터 → 백업 파일 받기`(JSON)로 **가끔 백업**해 두세요. `이 백업으로 바꾸기`로 복원돼요.
- 여러 사람이 같은 데이터를 보게 하려면(예: 비밀번호 없이 누구나 보기) 서버·DB 연결이 필요해요. 이건 **다음 단계**예요. (저장 코드가 `js/store.js` 한 파일로 분리돼 있어서 그 파일만 바꾸면 돼요)

## 계산식

| 지표 | 식 | 나누는 값이 0이면 |
|---|---|---|
| 클릭률 CTR | 클릭 ÷ 노출 × 100 | `-` |
| 클릭당 비용 CPC | 비용 ÷ 클릭 | `-` |
| 전환당 비용 CPA | 비용 ÷ 전환 | `-` |
| 전환율 | 전환 ÷ 클릭 × 100 | `-` |
| 소진율 | 집행액 ÷ 예산 × 100 | — |
| 예상 최종 집행액 | (집행액 ÷ 경과 일수) × 전체 일수 | — |

- 합계 기반으로 계산해요. (예: 기간 전체 CTR = 전체 클릭 ÷ 전체 노출 — 일별 CTR의 평균이 아니에요)
- 집행액은 **그 캠페인의, 예산 기간 안에 있는 성과 비용의 합**이에요.
- 같은 캠페인의 예산 기간이 겹치면 겹친 기간의 집행액이 각각에 중복 계산돼요 (화면에 안내가 떠요).
- 차트에서 **데이터를 입력하지 않은 날은 선이 끊겨요** (0원으로 그리지 않아요). 0원을 입력한 날만 0으로 표시돼요.

## 한도와 알려진 한계

- 캠페인 100개 · 기록 5000 · 성과 20000 · 예산 500 · 소재 1000개. 브라우저 저장 공간(보통 5MB 안팎)이 먼저 찰 수도 있어요. 가득 차면 화면에 안내가 떠요.
- 기록·소재의 **내용 수정**은 없어요. (지우고 다시 쓰기. 소재는 상태 변경과 점검 항목 추가·삭제는 가능)
- 어도비 계정과 자동으로 연동되지는 않아요. 숫자는 직접 입력하거나 CSV로 넣어요.

## 폴더 구조

```
ads/
├── index.html          화면 뼈대
├── css/style.css       기본 색상·카드·버튼·다크 모드
├── css/ads.css         탭·지표·표·차트·예산·소재·데이터 창 스타일
└── js/
    ├── calc.js         날짜·지표·예산·검색 계산 (화면과 무관한 순수 함수)
    ├── csv.js          CSV 읽기/쓰기 + 가져오기 규칙
    ├── store.js        데이터 저장소 (브라우저 저장 · 백업) ← 나중에 DB로 교체할 부분
    ├── sample.js       예시 데이터
    ├── ui.js           화면 공통 도우미 (입력한 글은 항상 글자 그대로 출력 → 스크립트 실행 안 됨)
    ├── charts.js       꺾은선 차트 (SVG, 외부 라이브러리 없음)
    ├── records.js · performance.js · budget.js · creatives.js   탭별 화면
    ├── data.js         데이터 창 (CSV 가져오기/내보내기 · 백업 · 예시 · 전체 삭제)
    └── app.js          탭·캠페인·다크 모드 조율
```
