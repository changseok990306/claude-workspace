# 어도비 (`ads/`)

어도비 광고 계정을 운영하면서 **캠페인별 히스토리와 소재일정**을 관리하는 웹페이지예요.
서버나 설치가 필요 없고, `index.html` 하나로 열려요. 다크 모드를 지원해요 (우측 상단 스위치).

## 열어 보기

1. `ads/index.html` 파일을 **더블클릭** (크롬·엣지 등 브라우저로 열려요. 인터넷이 없어도 돼요)
2. 처음이라면 **“예시 데이터로 둘러보기”** 버튼을 눌러 보세요. 가짜 캠페인 3개가 들어가요.
   - 지우고 싶으면 “예시 ·”로 시작하는 캠페인을 삭제하거나 `데이터 → 모든 데이터 지우기`.

## 화면 구성

위쪽 탭 2개 + 왼쪽 캠페인 목록이에요. 왼쪽에서 캠페인을 고르면 두 탭 모두 그 캠페인만 보여 줘요. (“전체”는 모두)
캠페인마다 색이 달라서 어디서든 구분돼요. 왼쪽 위 로고는 어도비 A 문양(`img/adobe-mark.svg`)이에요.

| 탭 | 하는 일 |
|---|---|
| **히스토리** | 캠페인별로 날짜와 메모를 남겨요. 날짜 최신순(위가 최신), 실시간 검색(내용·날짜·캠페인 이름), 삭제 |
| **소재일정** | 광고 소재를 **준비 / 집행 중 / 종료**로 나눠 관리해요. 소재마다 점검 체크리스트(규격·문구·링크·UTM·승인 등)를 체크하고, 종류 필터·검색을 지원해요 |

## 데이터 넣기

**1) 직접 입력** — 각 탭의 입력 칸 (소재일정은 “＋ 소재 추가” 줄을 눌러 펼쳐요)

**2) 히스토리 CSV 업로드** — 우측 상단 `데이터 → 히스토리 CSV 가져오기`
- 파일을 고르면 **바로 반영하지 않고 미리보기**를 먼저 보여 줘요 (몇 행을 읽었는지, 문제가 있는 줄 번호와 이유, 새로 만들어질 캠페인).
- 문제가 있는 줄은 건너뛰고 나머지만 가져와요. 파일은 이 브라우저 안에서만 읽어요. 어디로도 올라가지 않아요.
- `양식 CSV 받기`로 빈 양식을 받아 채우면 편해요. 엑셀·구글 시트에서 “CSV(UTF-8)”로 저장하세요. (최대 2MB, 5000행)

| 필요한 열 (한글/영어 모두 가능) |
|---|
| **날짜**(date) · **캠페인**(campaign) · **내용**(content, memo) |

- 날짜는 `2026-11-08`, `2026/11/8`, `2026.11.08`, `20261108`, `2026년 11월 8일` 모두 읽어요.
- 파일에 없는 캠페인 이름은 **자동으로 새 캠페인으로 만들어요** (체크를 끄면 그 행은 건너뛰어요).
- 같은 파일을 두 번 가져오면 히스토리가 **중복으로 들어가요** (히스토리는 덮어쓰기가 없어요).
- `데이터 → 히스토리 내보내기`로 내보낸 파일은 그대로 다시 가져올 수 있어요. (엑셀 수식 실행을 막으려고 `=`로 시작하는 글 앞에 `'`가 붙지만, 다시 가져올 때 자동으로 떼요)

## ⚠️ 데이터는 어디에 저장되나요?

**지금 쓰고 있는 이 브라우저 안에만** 저장돼요 (브라우저의 `localStorage`).

- 새로고침·창 닫기에는 남아 있어요.
- **다른 컴퓨터·다른 브라우저·시크릿 창에서는 안 보여요.** 보는 사람과 공유되지도 않아요.
- 브라우저의 “사이트 데이터 삭제”를 하면 **사라져요**. → `데이터 → 백업 파일 받기`(JSON)로 **가끔 백업**해 두세요. `이 백업으로 바꾸기`로 복원돼요.
- 여러 사람이 같은 데이터를 보게 하려면(예: 비밀번호 없이 누구나 보기) 서버·DB 연결이 필요해요. 이건 **다음 단계**예요. (저장 코드가 `js/store.js` 한 파일로 분리돼 있어서 그 파일만 바꾸면 돼요)

## 이전에 있던 “성과 · 예산·일정” 탭

공개용 페이지에는 맞지 않아 **없앴어요.** 예전에 그 탭에 입력해 둔 데이터가 브라우저에 있었다면, 새 버전을 처음 열 때 **지워지기 전에 브라우저 안의 별도 칸(`ads-data-v1-removed`)에 한 번 복사해 둬요.** (화면에는 보이지 않아요. 필요하면 알려 주세요)
코드는 git 태그 `backup-ads-before-trim`에 그대로 남아 있어서 언제든 되살릴 수 있어요.

## 한도와 알려진 한계

- 캠페인 100개 · 히스토리 5000 · 소재 1000개. 브라우저 저장 공간(보통 5MB 안팎)이 먼저 찰 수도 있어요. 가득 차면 화면에 안내가 떠요.
- 히스토리·소재의 **내용 수정**은 없어요. (지우고 다시 쓰기. 소재는 상태 변경과 점검 항목 추가·삭제는 가능)
- 소재일정에는 아직 **날짜(집행 시작·종료일) 칸이 없어요.** 상태(준비/집행 중/종료)와 체크리스트로 관리해요.
- 어도비 계정과 자동으로 연동되지는 않아요.

## 폴더 구조

```
ads/
├── index.html          화면 뼈대
├── img/adobe-mark.svg  로고 (어도비 A 문양)
├── css/style.css       기본 색상·카드·버튼·다크 모드
├── css/ads.css         로고·탭·소재일정 보드·데이터 창 스타일
└── js/
    ├── calc.js         날짜·검색·점검 진행률 계산 (화면과 무관한 순수 함수)
    ├── csv.js          CSV 읽기/쓰기 + 히스토리 가져오기 규칙
    ├── store.js        데이터 저장소 (브라우저 저장 · 백업) ← 나중에 DB로 교체할 부분
    ├── sample.js       예시 데이터
    ├── ui.js           화면 공통 도우미 (입력한 글은 항상 글자 그대로 출력 → 스크립트 실행 안 됨)
    ├── records.js      히스토리 탭
    ├── creatives.js    소재일정 탭
    ├── data.js         데이터 창 (CSV 가져오기/내보내기 · 백업 · 예시 · 전체 삭제)
    └── app.js          탭·캠페인·다크 모드 조율
```
